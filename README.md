# 🚀 SQL Master: İleri Seviye T-SQL ve Optimizasyon

Bu depo, bir **İş Zekası ve Veri Ambarı Geliştiricisi** olarak MS SQL Server ve `AdventureWorks2022` örnek veri seti üzerinde gerçekleştirdiğim ileri seviye veritabanı programlama, kontrol akışı (control-of-flow) ve performans iyileştirme senaryolarını içermektedir.

Sorgular, gerçek dünya senaryolarına uygun olarak kodlanmış olup performans (Execution Plan) odaklı yaklaşımlar barındırmaktadır.
